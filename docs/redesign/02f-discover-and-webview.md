- **常用**最多 8 格，「编辑」进入拖拽排序 + 增删（替代旧版「底栏固定模块」）；长按底栏「发现」Tab 弹出前 4 个的快捷环。

- 街机厅点开为小面板：`史莱姆 / 打地鼠 / 裂隙`。进入前若检测到另一端正在对局（`arcade-standby`），弹出原生提示：`另一台设备正在对局，保护已生效，避免进度覆盖` `[知道了]`。
- **站宠**：不做全局悬浮桌宠（遮挡、耗电、露馅风险）。替代方案：站宠屋设置里可开启「在摸鱼看板显示站宠」——在看板卡右下角显示 48dp 待机动作，点按播放回应动作。
- 状态摘要依赖轻量接口；拿不到时只显示模块名，不显示占位骨架（避免空卡噪音）。

## 4. 无壳 WebView 容器规范（P2 模块统一外壳）

```
┌──────────────────────────────────────┐
│ (‹) 鱼鱼谷                   (↻)(⋯)  │ ← 悬浮胶囊工具条，半透明，3s 无操作淡出
│                                      │   顶部下滑 / 点按顶部 24dp 区域唤回
│                                      │
│        [ 网页画布全屏沉浸 ]           │
│   （网页自身顶栏由注入 CSS 隐藏，      │
│     避免「双顶栏」）                  │
│                                      │
└──────────────────────────────────────┘
⋯ 菜单：固定到常用 / 在浏览器打开 / 复制链接 / 💬 打开群聊抽屉
```

| 规则 | 说明 |
|---|---|
| 登录态 | 与原生共享 `PersistentCookieJar`，不再要求登录 |
| 离线资源 | `WebAssetCache` 静态资源缓存；首次加载显示品牌色细进度条 |
| 返回 | 系统返回先走网页历史（`canGoBack`），到根后退出容器；**不拦截**左右边缘返回手势 |
| 画布手势冲突 | 鱼鱼谷「手指划过一排连续播种」等横向拖动：网页声明需要的区域，由容器调用 `setSystemGestureExclusionRects` 仅排除画布底部 200dp 内的左右边缘（Android 上限），其余区域保留系统返回 |
| 状态栏 | 游戏类全屏沉浸（隐藏状态栏，下滑唤出）；书房保留状态栏 |
| 伪装/老板键 | P2 模块在伪装态**完全不可达**；若用户正在 WebView 中触发老板键，WebView 暂停（`onPause` + 静音）并被云文档覆盖 |
| 音效 | 鱼鱼谷 WebAudio 音效开关在网页内；容器在切后台/老板键时强制暂停音频 |

### 4.1 书房：原生协作工具条

书房阅读器（WebView）底部额外叠加 **原生** 协作条（阅读时随网页工具条一同显隐）：

```
┌──────────────────────────────────────┐
│ [💬 群聊]   [✂ 摘录分享]   [☰ 目录]   │
└──────────────────────────────────────┘
```

| 操作 | 行为 |
|---|---|
| 💬 群聊 | 原生半屏群聊抽屉（选群 → 原生聊天组件，可完整收发），下拉收起继续读；阅读位置不变 |
| ✂ 摘录分享 | 网页回传选中文本（或当前句，≤1600 字）→ 原生 Sheet 预览摘录卡（书名/章名/纸色）→ 选群 → 发送；发送后可选「去群里看看」直接进入会话 |
| ☰ 目录 | 交给网页目录（章节搜索、80 节分页） |

- 阅读设置（4 纸色、3 字体、字号、行距、页宽）、云书签同步与冲突提示（`另一设备已更新，选择覆盖或同步`）、NSFW 书籍 18 岁确认均由网页承载。
- 游客：可读公共书架，书签存本地；群聊/摘录按钮点按 → 登录面板。
- 「我的创作」（`/novels/studio`）同容器；AI 续写的上下文字数与自费确认由网页弹出，容器不做额外拦截。
