# 04 · 全站交互手势总表与避让规范

> 对应交接文档 **交付物 4**，落实 **红线 5**（系统边缘返回避让）与 **红线 6**（键盘/滚动）。

---

## 1. 全局避让规则（所有页面先遵守这些）

| # | 规则 | 数值 |
|---|---|---|
| G1 | **系统边缘返回热区**：屏幕左右各 `24dp` 内起始的横向拖动，一律交给系统返回 | 24dp（以 `WindowInsets.systemGestures` 实际值为准，取较大者） |
| G2 | 页面内横向手势（左滑引用、轮播、标签横滑、代码块横滑、模式切换滑动）**起点必须在热区之外**；热区内起始的拖动不响应页面手势 | — |
| G3 | **不主动申请** `setSystemGestureExclusionRects`；唯一例外：WebView 游戏画布 / 打码画板的底部 200dp 区域（Android 单边上限 200dp） | — |
| G4 | 横纵向判定：拖动前 `8dp` 内水平位移 > 垂直位移 × 1.5 才判为横向，否则交给纵向滚动 | touchSlop 8dp，比例 1.5 |
| G5 | 底部 `手势导航条` 区域（底部 inset）内不放可拖动控件；底部互动栏、输入栏位于 inset 之上 | — |
| G6 | 嵌套滚动：内层横滑容器（轮播、标签行）只消费横向；纵向一律冒泡给外层列表 | — |
| G7 | 软键盘：所有含输入框页面使用 `imePadding` + 逐帧 inset 动画；键盘弹起时**隐藏 FAB 与底栏** | — |
| G8 | 双击只在**没有单击冲突**或单击可接受 250ms 延迟的位置使用（图片查看器缩放、沉浸竖翻点赞） | 双击窗口 250ms |
| G9 | 长按统一 `400ms`，触发时 10ms 触感 | 400ms |
| G10 | 所有破坏性操作（删除、撤回、退出群）走确认，不绑定手势 | — |

## 2. 全局手势

| 手势 | 行为 | 冲突消解 |
|---|---|---|
| 系统返回（左/右边缘滑动、返回键） | 关闭最上层浮层 → 返回上一页 → 根页面时：开启「连滑两次返回」则计数，否则退出到桌面 | 浮层存在时不计数；450ms 窗口；老板键态单次返回被吞 |
| 连滑两次系统返回 | 老板键 | 见 [03 §3.1](03-privacy-state-machine.md#31-触发器--可绑定动作) |
| 双击音量上 / 下 | 可分别绑定老板键 / 全图模糊 | 首次按下正常透传系统调音量（零延迟），350–420ms 内第二次按下消费并触发动作 |
| 屏幕朝下扣放 | 老板键 | 翻回不退出 |
| 轻晃手机 | 全图模糊开关 | WebView 游戏内停用；冷却 1.2s |
| 点底栏当前 Tab | 回顶 / 刷新 / 跳下一未读（按 Tab 定义） | — |
| 长按底栏 Tab | 图廊 → 浏览设置；发现 → 常用快捷环 | 其他 Tab 无动作 |

## 3. 分页面手势表

### 3.1 图廊

| 位置 | 手势 | 行为 | 冲突消解 |
|---|---|---|---|
| 信息流 | 上下滑 | 滚动；向下滑收起顶栏、隐藏 FAB；向上滑恢复 | 快速甩动时暂停已看计时 |
| 信息流顶部 | 下拉 | 刷新 | 仅在列表到顶时生效 |
| 卡片 | 单击 | 进详情；模糊卡按 `maskTap`：揭开 / 打开查看器 | — |
| 卡片 | 长按 | 快捷菜单（一句话/贴纸/收藏/转发/锚点…） | — |
| 卡片上的胶囊 / ♡ | 单击 | 跟投 / 回应 / 点赞 | 胶囊点击区最小 40dp 高 |
| 卡片内多图 | **不支持横滑**（卡片内只显示首图 + `1/4`） | — | 避免与列表滚动和边缘返回冲突 |
| 日期吸顶头 | 单击 | 跳到哪天 | — |
| 沉浸竖翻模式 | 上下滑 | 翻页（分页吸附） | — |
| 沉浸竖翻模式 | 双击 | 点赞（心形动画） | 单击 = 显隐控件，接受 250ms 延迟 |
| 沉浸竖翻模式 | 多图横滑 | 翻图 | 起点避让 G1 |
| 浏览设置 / 锚点横滑 | 横滑 | 滚动锚点卡片 | 起点避让 G1 |

### 3.2 帖子详情 & 看图舞台

| 位置 | 手势 | 行为 | 冲突消解 |
|---|---|---|---|
| 媒体区 | 单击 | 进沉浸看图舞台 | — |
| 媒体区（轮播） | 横滑 | 翻图 | G1/G2 |
| 标签行 | 横滑 | 滚动标签 | G1/G2 |
| 一句话胶囊 | 单击 / 点数字 / 长按自己的 | 跟投 / 参与名单 / 撤回 | 数字区独立点击热区 ≥ 32dp |
| 评论 | 长按 | 复制/回复/删除 | — |
| 详情页 | 上下滑 | 滚动；顶栏渐变实底 | — |
| 看图舞台 | 双指 | 缩放 | — |
| 看图舞台 | 双击 | 放大到 2.5× / 还原 | 单击 = 显隐控件（250ms 延迟可接受） |
| 看图舞台 | 下拉 | 关闭（背景渐透明） | 已放大时下拉先平移图片，到边缘后才触发关闭 |
| 看图舞台 | 横滑 | 翻图 | 已放大时先平移，到边缘后翻页；G1 |
| 长图舞台 | 上下滑 / 拖右侧进度条 | 阅读 / 快速定位 | 进度条位于右缘向内 24dp 之外 |
| 实况图 | 长按 | 播放动态 | 详情页内长按实况 ≠ 菜单（实况图上不弹菜单） |
| 视频 | 单击 / 拖进度条 | 播放暂停 / 跳转 | 进度条位于底部 inset 之上 |

### 3.3 消息 / 群聊 / 私信

| 位置 | 手势 | 行为 | 冲突消解 |
|---|---|---|---|
| 会话列表 | 长按 | 置顶/已读/免打扰 | **不做左右滑操作**（避免 G1 冲突） |
| 消息 | **左滑** | 引用回复 | 起点距右边缘 ≥ 32dp（比 G1 再宽 8dp），位移 ≥ 56dp 生效；纵向判定优先（G4）；松手前回到阈值内则取消 |
| 消息 | 长按 | 回应条 + 操作菜单 | — |
| 消息里的图片 | 单击 | 看图舞台 | 模糊态先揭开 |
| 头像 | 单击 / 长按 | 资料卡 / 插入 @ | — |
| 引用条（消息内） | 单击 | 跳到原消息并闪光 | — |
| 消息列表 | 上滑到顶 | 自动加载更早（锚点不动） | 见 [02c §3](02c-scenario-chat.md#3-视口锚定工程要求红线-6研发验收清单) |
| 回到最新浮标 | 单击 | 滚到底 | — |
| 代码块 | 横滑 | 横向滚动代码 | 起点避让 G1；代码块整体不消费纵向 |
| 猜词状态条 | 单击 / 下拉 | 展开情报板 | 下拉从状态条起始才触发，列表内下拉不触发 |
| 情报板底边 | 上下拖 | 调整高度 / 上推收起 | — |
| 输入框 | 左右滑 ≥ 48dp | 切换 聊天/猜/问 模式 | 仅在输入框为空或光标不在拖动轨迹时生效；起点避让 G1 |
| 输入框 | 单击 | 拉起键盘（遵守锚定规则） | 键盘弹起时情报板自动收缩 |
| 红包气泡 | 单击 | 拆包对话框 | — |

### 3.4 发帖 & 打码画板

| 位置 | 手势 | 行为 | 冲突消解 |
|---|---|---|---|
| 托盘 | 横滑 | 滚动托盘 | G1/G2 |
| 托盘项 | 单击 / 长按拖动 | 菜单 / 排序 | 长按 400ms 后进入拖拽，拖拽中禁止托盘自身滚动（靠边自动滚动） |
| 画板 | 单指拖 | 框选 / 涂抹 | 画布左右留 24dp 黑边，绘制起点永不在热区；底部 200dp 申请手势排除（G3） |
| 画板 | 双指 | 缩放平移 | — |
| 画板 | 双击 | 还原适配 | 单指单击无行为，不产生延迟问题 |
| 画板切图 | 底部 ‹ › 按钮 | 切换托盘下一张 | 不用横滑，避免与绘制冲突 |

### 3.5 发现 / WebView 容器

| 位置 | 手势 | 行为 | 冲突消解 |
|---|---|---|---|
| 常用宫格 | 长按 | 进入编辑（拖拽排序/移除） | — |
| WebView 顶部 24dp | 下滑 / 单击 | 唤回悬浮工具条 | — |

## 4. 键盘相关规范

| 页面 | 键盘弹起 | 键盘收起 |
|---|---|---|
| 群聊 / 私信 | 在底部：列表随键盘逐帧上移；在历史：保持首个可见消息不动；情报板收缩为状态条 | 情报板恢复上次高度；列表位置同理保持 |
| 帖子详情评论 | 底部互动栏变为评论编辑器；被回复评论滚到编辑器上方可见 | 恢复互动栏 |
| 解谜输入 | 互动栏隐藏，仅保留解谜输入行 | 恢复 |
| 发帖正文 | Markdown 快捷栏贴在键盘上方；发布按钮随之上移 | — |
| 搜索 | 进入即聚焦弹键盘；滚动结果列表时自动收起键盘 | — |
| 老板键触发时 | 先收起键盘再渲染文档 | — |
