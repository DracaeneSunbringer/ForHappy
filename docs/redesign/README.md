## 一页纸核心决策

| 议题 | 决策 | 一句话理由 |
|---|---|---|
| 底栏结构 | **4 Tab：图廊 · 消息 · 发现 · 我的** | 去掉「固定模块」「百宝箱」两个弱 Tab；消息合并群聊+私信，与飞书伪装结构天然同构 |
| 发帖入口 | **图廊页悬浮 FAB（下滑隐藏/上滑出现）**＋ 系统分享直达 ＋ 群聊图片「转图廊」 | 发帖频率远低于浏览，不值得常驻底栏中央；FAB 位于右下拇指热区 |
| 群聊 vs 私信 | **合并为「消息」一个会话列表**，顶部筛选胶囊 `全部/群聊/私信/@我/未读` | 一个收件箱心智；伪装时直接映射为飞书会话列表 |
| 副玩法 | 收进「**发现**」Tab：顶部摸鱼看板 + 常用模块宫格（可自定义固定）+ 动态顶栏模块 | 副玩法有入口但不喧宾夺主；Tab 名中性，正常态被瞟到也不扎眼 |
| 通知 | 图廊/消息顶栏 **铃铛 + 红点数字** → 全屏通知中心；「我的」一行入口 | 摘要克制，点开即全功能闭环（红线 4） |
| 图廊筛选 | 顶栏只放一个「**当前视图摘要胶囊**」，点开 **底部浏览设置面板**（拇指区） | 不再堆多层筛选栏，首屏全给梗图（红线 5） |
| 横向画廊 `hz` | 移动端改良为「**沉浸竖翻**」模式（全屏一帖一页，上下翻） | 横滑与轮播、系统边缘返回三方冲突；竖翻符合单手习惯 |
| 猜词屋 | **群聊同屏方案**：群聊顶部「猜词状态条」→ 下拉「情报板」（≤50% 屏高、挤压不遮挡）＋ 输入框三模式 `聊天/猜/问` 各自草稿 | 不分屏、不切页也能边看群边猜；完整功能（队列/历史/战绩/出题人工具）进全屏面板 |
| 防窥 | 三层严格分离；**任何一级视觉区都不放老板键/糊图按钮**；全部触发器收进「防窥与摸鱼」设置 | 红线 1、2 |
| 老板键退出 | 只有「同一盲操触发器再触发一次」或「长按文档标题 2s」两条暗门，**界面零退出按钮** | 红线 1 第三层 |
| 飞书伪装底栏 | **消息 · 通讯录 · 我的**（3 个都是真功能，无假 Tab） | 通讯录 = 真成员搜索/发起私信；避免假「云文档」Tab 露馅 |
| 网络内核 | 健康时**完全无感**；异常时顶栏下一行温和提示；全部诊断能力在「设置 › 网络加速与诊断」 | 伪装/老板键下禁止任何技术字样 |
| 更新 | 「我的」Tab 小红点 + 一次性非阻断 Snackbar；完整页在「设置 › 关于与更新」 | 不在「我的」主屏铺更新进度/镜像输入框 |

## 评审已拍板的核心业务与技术决议

> 以下议题均已在 v1.1 定稿阶段核实网站源码并经产品确认，设计稿已同步修订完毕：

1. **猜词屋消息隔离机制（已对照 `guess-room.js` 核实）**：猜答案（`!词`）、问是非（`?问题`）与 `@欢欢 线索` 全部走猜词专区独立接口，**不会发进主群聊消息流**；主群仅接收开局卡片与结算通知卡片。设计已删去冗余的「猜词折叠摘要」与相关设置开关（见 [02c §4.5](02c-scenario-chat.md#45-猜词与主群聊消息边界服务端隔离机制)）。
2. **飞书伪装群名与成员名映射**：采纳可配置的「工作化别名」策略——每日图廊对应 12 个轮换工作群与 40 位同事姓名，真实群聊支持本地别名映射（用户可改备注）并配备「成员显示为同事姓名」开关，避免列表露馅（见 [03 §5.3](03-privacy-state-machine.md#53-真实群聊私信与每日工作群的融合规则)、[03 §6](03-privacy-state-machine.md#6-防窥与摸鱼设置页)）。
3. **外部与第三方红包方案（采纳方案 3A）**：站内 D 币、解谜与原生 LDC 红包 100% 原生拆包与填写参数（原生 LDC 仅发包扣款步骤跳 `credit.linux.do` 无壳 WebView 授权回落）；转发的第三方 HB / Fish / 外部链接红包在原生弹窗展示状态快照并提供「一键复制口令」，通过内置加速 WebView 打开对应平台完成领取或发包（见 [02c §5.1–5.2](02c-scenario-chat.md#5-全能红包)）。
4. **伪装模式下发帖、回应与评论直接复用「工作群 / 论坛盖楼」原生机制**：飞书伪装取消工作群禁言条，直接在工作群底部标准输入栏选图/输入发送 = 发帖，左滑/长按回复挂引用发送或进话题回复串 = 评论，长按表情条 = 点赞与贴纸回应；LINUX DO 伪装同理通过「回复主题（盖新楼）」发帖、点某楼 `↩ 回复` 评论（见 [03 §5.2](03-privacy-state-machine.md#52-飞书-im工作群内浏览与直接发言发帖每日图廊群)、[03 §5.6](03-privacy-state-machine.md#56-伪装态下的发帖与设置)）。
5. **Android Quick Settings 快捷磁贴**：暂不做系统下拉控制中心磁贴，防止借手机或下拉通知栏时的误触露馅风险（见 [03 §3.3](03-privacy-state-machine.md#33-触发器生效前提)）。
6. **三项技术与交互修正（全部采纳）**：① 开启 `FLAG_SECURE` 时在老板键下**全程保持不摘挂**（杜绝 `onStop` 多任务缩略图竞态漏图与国产 ROM 闪黑）；② 双击音量键**首次按下零延迟正常透传**系统调音量，不伤日常按键手感；③ 普通图廊卡片维持单击秒开详情 + 点 `♡` 赞，仅沉浸竖翻保留双击点赞，消除 `250ms` 等待延迟。
